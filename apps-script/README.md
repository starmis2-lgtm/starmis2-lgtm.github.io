Script project bound to the Google Sheet "Copy of DEO-Dashboard".

Script ID: `1XgDPrTpPw5hwpkvdYTXBa7r6WbSEda2uwZSCu1TfpdBRHNhyfEeyJC5J`

## Workflow

This copy is kept in sync by hand — no clasp, no Google auth from this
environment.

1. Paste a file's contents from the Apps Script editor into chat
2. Changes get made here, in this folder
3. Copy the updated file back into the Apps Script editor and save

Git history in this folder is the record of what changed and when, so an
older version can always be recovered.
